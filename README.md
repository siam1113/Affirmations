# Affirmations

A small Python command-line tool that asks how you're feeling and responds with a personal greeting and an affirmation.

## How it works

Run the program and answer a few prompts:

```bash
python main.py
```

You will be asked for:

1. Your name
2. Whether you are feeling happy (yes/no)
3. Whether you are feeling sad (yes/no)

Based on your answers, the tool prints a greeting and a short affirmation message.

## Project structure

- `main.py` — entry point that collects your input
- `greetings.py` — prints a personalized greeting
- `affirmations.py` — prints an affirmation based on your mood
